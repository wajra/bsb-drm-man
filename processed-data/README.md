# processed-data

All data resulting from processing the raw data in the `data/` folder by 
`R/pub_script_01_prep_all_data.R` script.  

1. `all_temperatures_glorys.csv` - Seasonal and annual temperatures in the NEUS derived using the GLORYS package.
2. `black_sea_bass_catch_at_length_spring_training.csv` - Catch at length data formatted from NEUS survey
used to fit the model
3. `black_sea_bass_F_by_age_all_subunits.csv` - FAA (fishing pressure at age) values for each subunit in the NEUS
4. `black_sea_bass_wt_age_age_mean.csv` - WAA (weight-at-age) values for each subunit in the NEUS
5. `subunit_information.csv` - Area calculations for each subunit in the NEUS
6. `subunit_abundances.csv` - Raw abundance in each subunit through time
